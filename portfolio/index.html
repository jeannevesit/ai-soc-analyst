NevesSec: Autonomous AI-Powered SOC Analyst

Designed and deployed a 24/7 serverless Security Operations Center pipeline in Google Cloud Platform. The system automatically ingests system logs, command indicators, and malicious URLs from honeypots, forwards them via webhooks, and invokes a Gemini AI L2 Analyst agent in n8n.

The agent automatically audits threat vectors, queries VirusTotal, tags attacks using MITRE ATT&CK techniques, blocks malicious source IPs in firewalls, and updates the custom Enterprise SIEM dashboard.
